# queens-student-page

Michael Chang's Queen's student page for CISC 121.

Live site: https://m-chang24.github.io/queens-student-page/

## How to open the site
Click the live site link above. Nothing needs to be downloaded.

## Files
- index.html: page content
- style.css: Queen's colours and layout
- me.jpg: profile photo (must stay in the main folder, next to index.html)

## How to update
Edit a file on GitHub and commit. The site updates automatically in about a minute.
